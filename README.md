## Como executar

Cada receita possui seu próprio projeto Next.js, localizado na pasta `next0`.

Para executar uma receita, entre na pasta correspondente. Por exemplo, para executar a Receita 20:

```bash
cd receita20/next0
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Depois, acesse [http://localhost:3000](http://localhost:3000/) no navegador.

Caso a porta 3000 esteja ocupada, o Next.js poderá utilizar outra porta, informada no terminal.
